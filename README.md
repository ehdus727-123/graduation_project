# 드로잉 레퍼런스 검증 도구

졸업 프로젝트(드로잉 특화 레퍼런스 서비스)의 기술 검증용 내부 웹앱입니다.
팀원이 각자 PC에서 실행하고, 태그·라벨·포즈·AI 예측은 **Supabase(DB)에 모여 모두가 같은 데이터를 봅니다.**

## 처음 한 번: 설치

1. **Python 3.14** 설치 (python.org). 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 이 폴더에서 터미널(PowerShell)을 열고:
   ```
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
   pip install -r requirements.txt
   ```
3. **접속 정보**: `.env.example`을 복사해 이름을 `.env`로 바꾸고, 팀장에게 받은 값을 넣습니다.
   - 팀원은 **publishable 키**(`sb_publishable_...`)를 씁니다. 키는 메신저 공개 채널·Git에 올리지 마세요.
4. **이미지(선택)**: 팀 공유 폴더의 `drawing_ref_test/`를 이 폴더에 복사하면 빠릅니다.
   없으면 DB에 등록된 이미지 주소에서 필요할 때 내려받습니다.

연결 확인: `python check_supabase.py` → "연결 테스트 통과"가 나오면 준비 끝.

## 매일: 실행

```
python -m streamlit run app.py
```

(`streamlit run app.py`도 되지만, "명령을 찾을 수 없다"고 나오면 위처럼 `python -m`을 붙이세요.)

브라우저가 열리면 **SPECTRUM 입장 화면**이 나옵니다. **팀원 이메일**을 넣고 "팀원으로 입장"을 누르세요.
- 저장할 때 쓰는 이름은 팀 명단의 이름으로 자동으로 정해집니다(사람마다 이름이 갈라지지 않음).
- 이메일이 안 맞으면 팀장에게 명단 등록을 요청하세요. 새로고침하면 다시 입장해야 합니다.
- 팀원이 아닌 사람은 "방문자이신가요? **입장하기**"로 모든 화면을 볼 수 있지만 저장·수정은 할 수 없습니다.

## AI 학습 (담당 PC)

태그 학습은 이미지가 많아 웹앱이 아니라 **이미지 파일(`drawing_ref_test/`)이 있는 PC 한 곳**에서 합니다. 결과는 DB로 공유되어 모든 팀원 화면(AI 추천, 예측 확인, 갤러리)에 반영됩니다.

1. (새 이미지를 추가했다면) DB에 등록 — 관리자 키가 있는 PC에서: `python migrate_to_supabase.py`
2. 학습: `python training.py --email 내이메일` (웹앱 입장에 쓰는 이메일)
   - 진행률·속도·남은 시간이 나옵니다. 1만 장 기준 약 6~7분, 메모리 최대 약 1.7GB.
   - 멈춰도 **같은 명령으로 다시 실행하면 이어서** 합니다. 열 수 없는 이미지는 건너뛰고 마지막에 알려 줍니다.
   - 예측은 다 올라간 뒤에만 팀 화면에 보입니다. 올리다 실패하면 팀 화면은 직전 학습 결과 그대로입니다.
3. 결과 확인: 웹앱 **자동 태깅 → 학습 현황**

## 함께 작업할 때 지킬 것

- 같은 이미지를 여러 명이 라벨링해도 됩니다(다수결). 분담하려면 라벨링 화면의 **"다른 팀원이 끝낸 이미지도 숨기기"**를 켜세요.
- 포즈 라벨링은 누군가 완료한 이미지를 자동으로 건너뜁니다. 특정 이미지를 같이 보려면 이미지 옆 **링크**를 복사해 보내세요.
- 잘 모르겠는 태그는 체크하지 말고 **보류**하세요. 보류한 태그는 저장되지 않습니다.
- 다른 팀원이 바꾼 태그 목록은 최대 30초 뒤에 보입니다(태그 관리의 🔄 새로고침으로 바로 갱신).

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| "Supabase 접속 정보 없음" | `.env` 파일 이름·위치 확인 (프로젝트 폴더 바로 아래, 확장자 없이 `.env`) |
| "DB에 테이블이 없습니다" / "권한(GRANT)" | 팀장에게: `supabase/schema.sql`을 Supabase SQL Editor에서 실행 |
| 배포된 웹 주소에서 '미리 계산' 버튼이 회색 | 서버 메모리가 작아 막아 둔 것입니다. PC에서 앱을 켜고 실행하면 결과가 DB로 공유됩니다 |
| `training.py`가 중간에 멈춤 | 같은 명령을 다시 실행하면 이어서 합니다(이미 추출한 이미지는 건너뜀) |
| "팀 명단에 없는 이메일" | 웹앱 입장에 쓰는 이메일을 넣었는지 확인. 명단 등록은 팀장에게 |
| 3D 마네킹이 안 뜸 | 터미널에서 `Ctrl+C`로 끄고 `python -m streamlit run app.py`로 다시 실행 |
| `.env`를 넣었는데 "접속 정보 없음" | 파일 이름이 `.env.txt`가 아닌지 확인 (탐색기 보기 → 파일 확장명 켜기) |
| `python`을 찾을 수 없음 | Python 설치 시 "Add to PATH"를 빠뜨림 → 다시 설치 |

개발 규칙·구조는 `CLAUDE.md`, 기능 명세는 `SPEC_*.md`를 보세요.
